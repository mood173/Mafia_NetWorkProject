# 10주차 개인 담당 구현 — 앱 흐름과 서버 응답 기반 화면 전환

## 현재 추가·변경한 주요 파일

- `common/src/main/java/StreamSystem/AppStream.java`
- `common/src/main/java/StreamSystem/gameStream.java`
- `client/src/main/java/StreamSystem/StreamManager.java`
- `client/src/main/java/com/mafia/client/stream/GameStream.java`
- `client/src/main/java/com/mafia/client/stream/ClientState.java`
- `verification/src/main/java/PersonalChecks.java`

전체 변경 내역은 이 주차 Git 커밋에서 확인한다. common 계약과 client 조립 코드는 내 구현이 호출·표시되도록 연결한 부분이다. 팀원 담당의 실제 기능 구현을 대신하지 않는다.

## 실제 코드

`client/src/main/java/StreamSystem/StreamManager.java`

```java
package StreamSystem;

import com.mafia.common.model.Phase;
import com.mafia.common.protocol.Message;

/**
 * 서버 응답을 앱 화면 상태와 게임 단계 표시로 옮기는 클라이언트 관리자.
 * 규칙/승패/시간 만료는 서버 GameSession이 판정한다.
 * 실제 Swing 화면 전환은 GameStream이 수행한다.
 */
public final class StreamManager {
    private AppStream appState = AppStream.main;
    private gameStream displayedGamePhase = gameStream.WAITING;

    public AppStream app() { return appState; }
    public gameStream game() { return displayedGamePhase; }

    /** 성공 응답으로 화면을 결정한다. 요청 전송 자체나 ERROR로는 전환하지 않는다. */
    public AppStream accept(Message serverMessage) {
        switch (serverMessage.type()) {
            case LOGIN_OK -> showLobby();
            case ROOM_STATE -> {
                // 다른 참가자의 방 갱신이 내 게임/결과 화면을 되돌리지 않게 한다.
                if (appState == AppStream.Lobby || appState == AppStream.FrontDesk) {
                    appState = AppStream.FrontDesk;
                }
            }
            case GAME_START -> {
                appState = AppStream.GameScene;
                displayedGamePhase = gameStream.WAITING;
            }
            case PHASE_CHANGE, GAME_STATE -> {
                Phase serverPhase = Phase.valueOf(serverMessage.field(0));
                displayedGamePhase = gameStream.from(serverPhase);
            }
            case GAME_END -> {
                appState = AppStream.End;
                displayedGamePhase = gameStream.GAME_END;
            }
            case ROOM_LEFT -> showLobby();
            default -> { }
        }
        return appState;
    }

    public void disconnected() {
        appState = AppStream.main;
        displayedGamePhase = gameStream.WAITING;
    }

    private void showLobby() {
        appState = AppStream.Lobby;
        displayedGamePhase = gameStream.WAITING;
    }
}
```

## 확인한 결과

- Java 17 툴체인 / Gradle 9.8.2에서 이 주차 스냅샷 `build` 성공.
- 개인 검사 7개 통과(이 주차까지 누적 검사 수).
- 주요 관측: 로그인 성공/실패 및 화면 상태 투영.

밤 결과는 verification의 FakeCharacters가 고정값을 돌려준다. 이는 GameSession의 결과 적용을 검증하며 마피아/의사/경찰 능력 알고리즘의 정확성을 검증하지 않는다. UI 테스트도 테스트용 연결 및 빈 능력/채팅 패널을 사용한다.

## 이 체크포인트의 제한

게임 씬은 미리보기 자리표시자이며 게임 규칙은 아직 없다.

## 실행

프로젝트 루트에서:

```bat
gradlew.bat build
```

`client:run`은 기존 OfflineConnection을 쓰는 개인 UI 미리보기다. 실제 게임 실행은 팀원 Connection/방/캐릭터 구현과 조립한 뒤 확인해야 한다.
