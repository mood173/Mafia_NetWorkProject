# 12주차 개인 담당 구현 — 게임 세션·직업 배정·밤 단계

## 현재 추가·변경한 주요 파일

- `server/src/main/java/com/mafia/server/game/GameSession.java`
- `server/src/main/java/com/mafia/server/game/GameSessionFactory.java`
- `server/src/main/java/com/mafia/server/game/PhaseTable.java`
- `server/src/main/java/com/mafia/server/game/RoomChannel.java`
- `server/src/main/java/com/mafia/server/character/CharacterService.java`
- `verification/src/main/java/PersonalChecks.java`

전체 변경 내역은 이 주차 Git 커밋에서 확인한다. common 계약과 client 조립 코드는 내 구현이 호출·표시되도록 연결한 부분이다. 팀원 담당의 실제 기능 구현을 대신하지 않는다.

## 실제 코드

`server/src/main/java/com/mafia/server/character/CharacterService.java`

```java
package com.mafia.server.character;
import java.util.Map;
import java.util.Set;
/** 공동 계약. 판은 시점/생존, 캐릭터는 능력 유효성/결과 계산을 책임진다. */
public interface CharacterService {
    void beginNight(Set<String> alive, Map<String,RoleAbility> roles, Runnable onAllSubmitted);
    SubmitResult submit(String actor, NightAction action);
    NightResult endNight();
    void onPlayerLeft(String actor);
}
```

## 확인한 결과

- Java 17 툴체인 / Gradle 9.8.2에서 이 주차 스냅샷 `build` 성공.
- 개인 검사 20개 통과(이 주차까지 누적 검사 수).
- 주요 관측: 주입한 밤 결과 적용·개인 응답·만료 및 오래된 콜백 차단.

밤 결과는 verification의 FakeCharacters가 고정값을 돌려준다. 이는 GameSession의 결과 적용을 검증하며 마피아/의사/경찰 능력 알고리즘의 정확성을 검증하지 않는다. UI 테스트도 테스트용 연결 및 빈 능력/채팅 패널을 사용한다.

## 이 체크포인트의 제한

밤 결과까지의 단계다. 토론 단계에서 대기하며 투표/승패는 13주차, 이탈은 14주차 구현이다.

## 실행

프로젝트 루트에서:

```bat
gradlew.bat build
```

`client:run`은 기존 OfflineConnection을 쓰는 개인 UI 미리보기다. 실제 게임 실행은 팀원 Connection/방/캐릭터 구현과 조립한 뒤 확인해야 한다.
